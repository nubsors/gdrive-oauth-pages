# Google Drive OAuth — Branding Pages

Static pages used as the **Application home page** and **Application privacy policy link**
for a private, single-user Google OAuth application (rclone → the owner's own Google Drive).

These exist because Google's Auth Platform requires a homepage URL and a privacy policy URL
on a domain you control before it will enable **Publish App** for an External app — even for
personal, single-user use.

- `index.html` — application home page
- `privacy.html` — privacy policy

No scripts, no analytics, no tracking. Static HTML only.
