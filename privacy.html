Privacy Policy

rclone Google Drive Access — last updated 2026

Summary

This application is a private, single-user tool. It does not collect, store, or share personal data. Full stop.

Data accessed

After the owner authorizes it, the application accesses the owner's own Google Drive files using the https://www.googleapis.com/auth/drive scope, in order to list, read, upload, and download those files.

Data collection and storage

No data is collected or stored by this application. File transfers occur directly between the owner's computer and Google's servers. Nothing is routed through, or retained by, any server operated by this application, because it operates no servers.

Data sharing

No data is transmitted to any third party. No analytics, tracking, advertising, or telemetry of any kind is used.

Credentials

The OAuth token issued by Google is stored locally on the owner's own machine, in the rclone configuration file. It never leaves that machine. The owner may revoke access at any time via their Google Account permissions page, or by deleting the token.
